ISSUE FOUND — CONFIG DIRECTORY LOCATION
===============================================================================

The config directory was initially created at the repository root:

This caused Vite to fail when App.tsx attempted to import:

because App.tsx is located inside src/.

The directory was moved to the correct location:

src/config/instruments.ts

Final relevant source structure:

src/
├── config/
│   └── instruments.ts
├── types/
│   └── marketData.ts
├── assets/
├── App.css
├── App.tsx
├── index.css
└── main.tsx

After moving the configuration file, Vite successfully resolved the import.
